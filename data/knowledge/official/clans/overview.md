# Кланы: общая информация

Клан объединяет игроков для совместного развития, строительства, боёв, турниров, осад и атак других кланов.

Кланы с высоким рейтингом получают кредитные награды.

Создание: `Создать клан Название`. Создание бесплатно, название должно быть уникальным.

Основные команды:
- `Топ кланов` — мировой рейтинг;
- `Инфо топ 10 клан` — информация о клане по месту в рейтинге;
- `Клан` — текущий клан;
- `Меню клана` — меню в групповом чате;
- `Участники клана` — участники и права;
- `Инфо топ 1 участник клана` — информация об участнике по месту;
- `События клана` — история событий;
- `Покинуть клан`;
- `Удалить клан` — только через бота.

Изменения клана:
- название — 50 кредитов, повторные изменения в течение 60 минут дорожают в 2 раза;
- картинка — 50 кредитов;
- описание — 30 кредитов, удаление через `...: пусто` бесплатно;
- приветствие — 30 кредитов, удаление через `...: пусто` бесплатно.

Для клановых действий рекомендуется отдельный групповой чат с ботом.
