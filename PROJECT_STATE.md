# PROJECT STATE

## 2026-09-05 — Architecture reset

Старая экспериментальная система самообучения удалена. Q-learning, memory, transitions, strategy, reward, stats, perception, Qwen analyst и knowledge writer/retrieval больше не являются частью агента.

Оставлены базовые компоненты, которые не зависят от конкретной стратегии обучения:
- `config.py` — настройки Telegram и аккаунтов;
- `bot/telegram_client.py` — подключение к Telegram, получение сообщений и кнопок;
- `bot/models.py` — базовые структуры данных;
- `main.py` — запуск нескольких аккаунтов;
- `data/knowledge/official/` — существующая справочная информация об игре, пока сохранена как исходный материал.

Создан минимальный `bot/agent.py`. Сейчас он только наблюдает сообщения игры. Новую архитектуру будем строить постепенно и проверять каждый слой на реальной игре.

## Принцип новой архитектуры

Не пытаться сразу написать огромную систему, которая знает всю игру.

Сначала строим минимальный цикл:

`наблюдение → действие → результат → опыт → обучение`

Механики и представление состояния будем добавлять только тогда, когда они действительно нужны агенту для обучения.
